# Epic Question Bank

## Setup and Triage

- "What triggered this idea or problem now?"
- "Which users or teams feel this most directly?"
- "What makes this broad enough to deserve epic discovery?"
- "If this were much smaller, what would the story-sized version be?"

## Reframing

- "What problem does this solve for the user?"
- "What would the user do instead if this did not exist?"
- "What cost or friction does that workaround create?"
- "What is explicitly out of scope for this exploration?"

## JTBD and Four Forces

- "In what situation does this job appear?"
- "What is the user trying to achieve functionally, emotionally, and socially?"
- "What pushes them away from the current state?"
- "What pulls them toward a new solution?"
- "What creates anxiety about changing?"
- "What existing habit would this need to replace or fit into?"

## Edge Cases

- "What happens in empty state?"
- "What happens at the limits of input size or concurrency?"
- "Who could be harmed or disrupted even if they are not the target user?"
- "What accidental or unexpected behavior should still be safe?"

## Convergence

- "What is the root pain rather than the symptom?"
- "What is the one-sentence problem statement?"
- "What outcome would prove this matters?"
- "If only one slice could be solved first, which one creates the most value?"

## Assumptions

- "What are we assuming about the problem?"
- "What are we assuming about the user's willingness to change?"
- "What are we assuming about technical feasibility?"
- "What evidence supports this assumption today?"
- "If this assumption is wrong, how badly does the epic break?"

## Exit Gate

- "What is still uncertain about value?"
- "What usability friction is still unresolved?"
- "What technical constraint is still only partially understood?"
- "What business signal tells us this is worth doing?"
