# Epic Frameworks

## Double Diamond

Use divergence to widen the problem space before using convergence to narrow it.
Do not treat these as labels only. The point is to expand first, then choose with evidence.

## JTBD

Investigate the job from three dimensions:
- functional: what the user is trying to get done
- emotional: how they want to feel while doing it
- social: how they want to be perceived by others

## Four Forces

Use the forces of progress to understand change:
- push from the current pain
- pull toward a better future
- anxiety about the new option
- habit that anchors the current behavior

## Assumption Mapping

Sort assumptions by:
- impact if wrong
- evidence available now

High-impact, low-evidence assumptions are the most dangerous and must be explicit before planning.

## Theory of Constraints

Look for the bottleneck that most limits progress. Use it to prioritize what matters rather than spreading attention evenly.

## Opportunity Solution Tree

Connect:
- one outcome
- one or more user opportunities
- candidate solution directions
- assumptions that must hold true
