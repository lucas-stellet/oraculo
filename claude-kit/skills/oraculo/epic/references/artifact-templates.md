# Epic Artifact Templates

## Epic Requirements Document

Use this structure:

1. Title
2. Raw Idea
3. Reframed Problem
4. Motivation and Context
5. Target Outcome
6. Requirement Set or Job Stories
7. Scope Boundaries
8. Assumption Register
9. Codebase Impact Summary

## Codebase Impact Summary

Capture:
- related components or modules
- relevant existing tests or behaviors
- architectural constraints
- reuse opportunities
- open technical risks

## Assumption Register

For each important assumption, record:
- category
- statement
- impact if wrong
- current evidence
- resulting risk
- whether it must be resolved before planning

## Approval Handoff Notes

When submitting for approval, make clear:
- what artifact was saved
- what decision the reviewer is making
- which phase to return to if the verdict is not approved
